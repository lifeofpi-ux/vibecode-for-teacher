프롤로그 P-3 소요 시간: 약 4분

이 책을 통해 만들게 될 것들, 그리고 얻게 될 것들

1. 상상을 실제 도구로 바꾸는 4가지 파트의 디지털 여정

이 책의 모든 챕터는 실제 교실 현장에서 겪는 고충을 해결하는 결과물을 직접 만드는 과정을 담고 있으며, 바이브 코딩으로 서비스를 만들어가는 각 개념을 체계적으로 설명합니다.

매 단계마다 직접 실습할 수 있는 핵심 예제를 제공하여 여러분의 바이브 코딩 결과물이 완성되는 경험을 선사합니다. 지금부터 우리가 함께 진행할 네 가지 파트를 소개합니다.

[Part 1] 문제 발견 — 내 불편함이 앱이 되기까지 (Hello, World)

AI 도구를 활용해 코드를 몰라도 단 5분 만에 웹앱의 뼈대를 만듭니다.

  • 스마트 출석 체크 앱: 등교 시간 출결을 웹앱으로 기록하고 브라우저 저장소에 실시간 보관
  • 글쓰기 타임라인 SNS: 학생들이 글을 입력하면 피드에 공유되는 학급 전용 SNS

[Part 2] 앱에 지식을 더하다 — 구글 AI Studio & API 연동

외부 API를 연동하여 혼자서 구현하기 어려웠던 강력한 지능형 기능을 연결합니다.

  • 오늘의 급식 메뉴 알리미: 교육청 공공데이터를 연동해 실시간 급식 메뉴와 알레르기 정보 표시
  • 사진 읽는 AI 비전 도구 & 글쓰기 튜터: 학습지 사진을 찍으면 AI가 글씨를 인식(OCR)하고 맞춤 피드백 제공

[Part 3] 앱에 클라우드 기능을 심다 — Supabase 클라우드 DB 연동

데이터를 영구적으로 저장하고 지속 가능한 서비스로 발전시킵니다.

  • 날짜별 To-Do 일정 관리 앱: Supabase 데이터베이스와 연동하고 사용자 인증(Auth) 보안 적용

[Part 4] 진짜 개발자처럼 일하기 — Antigravity IDE & MCP 환경

내 컴퓨터(로컬)에서 직접 코드를 조립하고 배포하는 개발 환경을 경험합니다.

  • 나만의 HTML 프로필 & 실시간 칭찬 협업 보드: MCP로 Supabase Realtime을 연결해 학생들이 실시간으로 소통하는 인터랙티브 보드 구현

2. 여정을 마치면 얻게 될 보이지 않는 자산들

  • 기술적 주권 (Tech Sovereignty): 남이 만들어준 도구의 불편함을 참고 쓰지 않고, "내가 직접 고쳐서 쓰면 되지"라는 자신감이 생깁니다.
  • 초고효율 AI 대화 능력: 단순한 일상 대화를 넘어 복잡한 소프트웨어 시스템을 설계하기 위해 AI를 리딩하는 능력을 갖추게 됩니다.
  • 에듀 프로토타이퍼(Edu-Prototyper)로서의 정체성: 지식 전달자를 넘어 기술을 활용해 교육 현장을 혁신하는 메이커로 거듭납니다.

3. 완벽할 필요는 없습니다, '작동'하면 충분합니다

우리가 만드는 앱이 대기업 서비스처럼 화려할 필요는 없습니다. 디자인이 조금 투박해도, 코드가 조금 엉성해도 괜찮습니다. 가장 중요한 것은 '나와 내 학생들의 불편함을 정면으로 해결하고 있는가'입니다.

문법 오류나 오타는 AI가 신속하게 수정해 줄 것입니다. 여러분은 그저 "우리 반 아이들에게 이런 기능이 꼭 필요해"라는 그 교육적 방향성만 유지해 주세요.
