# Ch 4. 허용된 사용자만 접근 가능한 앱으로 변경하기

앞 챕터에서 사용했던 AI Studio의 To-Do 프로젝트 프롬프트 창을 다시 열어 입력합니다.

## Supabase Auth 인증 기능 추가 프롬프트

```
슈파베이스 데이터베이스에 접근 사용자 비밀번호를 저장하고, 앱 실행시 이 비밀번호를 입력하고 정확히 일치하여야 앱이 실행되도록 수정해줘.

1. 모달 창으로 비밀번호 입력 페이지를 구현하고, 비밀번호를 입력받도록 해줘.
2. 사용자 이메일은 admin@planner.vibe(변경 가능) 비밀번호는 VibeCoder2026! (변경 가능)으로 설정해줘.

프론트코드에서 비밀번호를 검증하는 것이 아니라 Supabase의 Auth 기능으로 사용자를 인증하도록 해줘. Supabase Auth 기능의 사용법도 함께 알려줘.
```

> 실행 후 AI가 제공하는 새로운 SQL 명령어를 Supabase의 SQL Editor에 붙여넣어 적용하고,
> Authentication → Users 메뉴에서 프롬프트에 적은 이메일/비밀번호로 사용자를 등록해야 합니다. (자세한 절차는 책 본문 참고)
